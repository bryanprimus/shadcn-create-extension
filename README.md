# shadcn/create Extension

A browser extension that replaces the **Heading** and **Font** pickers on
[ui.shadcn.com/create](https://ui.shadcn.com/create) with searchable
[shadcn Combobox](https://ui.shadcn.com/docs/components/base/combobox)
pickers, with the live preview updating as you hover and pick.

* The default list is the site's own fonts, grouped the same way, plus
  Gabarito and the fonts you picked before.
* Typing searches those and the ~1,900 [Fontsource](https://fontsource.org)
  families together, in the same categories, with no duplicates.
* Picking one of the site's fonts goes through the site's own picker, so the
  preset, Get Code and shared links stay correct.

## Install (development)

```sh
pnpm install
pnpm build            # Chrome, output in .output/chrome-mv3
pnpm build:firefox    # Firefox, output in .output/firefox-mv2
```

Chrome: open `chrome://extensions`, enable Developer mode, click
**Load unpacked** and pick `.output/chrome-mv3`.

`pnpm dev` starts a browser with the extension loaded and hot reload.

## Releases

Every push to `main` runs the tests and publishes a GitHub Release
(`v0.1.<run number>`) with the Chrome and Firefox zips
([`.github/workflows/release.yml`](.github/workflows/release.yml)).

To try a release: download the `chrome.zip` asset, unzip it, and use
**Load unpacked** in `chrome://extensions` (or Arc's extensions page).

### Chrome Web Store (optional)

The same workflow uploads to the Chrome Web Store once these repository
secrets exist: `CHROME_EXTENSION_ID`, `CHROME_PUBLISHER_ID`,
`CHROME_SERVICE_ACCOUNT_CLIENT_EMAIL`, `CHROME_SERVICE_ACCOUNT_PRIVATE_KEY`.
The first upload has to be done by hand in the developer dashboard to get the
extension ID.

## How it works

The create page is a Next.js app whose pickers are Base UI menus, and the
preview is a same origin iframe at `/preview/<base>/<item>`.

* `entrypoints/create.content.ts` hides the site's Heading and Font pickers
  and mounts two React comboboxes in their place, inside a shadow root so the
  extension's Tailwind build never touches the site. Theme tokens are
  inherited from the site's customizer panel.
* `components/ui/` holds shadcn's Combobox (and the Input Group, Button and
  Input it uses) in the **base-nova** style the create page itself is built
  with. They are generated by `scripts/vendor-shadcn.mjs` from a shadcn/ui
  checkout using the same transform as shadcn's registry build; the only
  change is a `container` prop on `ComboboxContent` so the popup can render
  inside the shadow root.
* Built-in fonts are applied by operating the site's hidden picker. Custom
  fonts are applied on top: `entrypoints/preview.content.ts` overrides the
  `--font-sans` / `--font-heading` inline styles the site writes in the
  preview iframe with an `!important` rule.
* Search uses the [Fontsource API](https://fontsource.org/docs/api/introduction)
  (`/v1/fonts` once, then `/v1/fonts/{id}` and `/v1/variable/{id}` for a
  picked font). Font files come from jsDelivr and are only downloaded for the
  weights and scripts the page renders.
* The selection lives in the tab's `sessionStorage`; picked fonts are
  remembered in the site's `localStorage`. The extension needs no permissions.

## Updating the shadcn components

```sh
git clone --depth 1 https://github.com/shadcn-ui/ui /tmp/shadcn-ui
SHADCN_COMMIT=$(git -C /tmp/shadcn-ui rev-parse --short HEAD) \
  node scripts/vendor-shadcn.mjs /tmp/shadcn-ui
```

## Bundling a font

Fonts from search need no code. To ship one inside the extension (works
offline), add the `@fontsource-variable/<slug>` package and an entry in
`BUNDLED_FONTS` in [`lib/fonts.ts`](lib/fonts.ts). The build copies the font
files from the package.

## Tests

```sh
pnpm typecheck
pnpm test:e2e
```

The e2e tests run the built extension in Chromium against
`e2e/fixture`, a trimmed replica of the create page (same Base UI picker
markup and iframe protocol). Fontsource and jsDelivr are mocked
(`e2e/fontsource-mock.ts`), so the tests run offline. Set `CHROMIUM_PATH` to use an existing Chromium
binary instead of the one Playwright downloads.

## Limitations

* Custom fonts are not part of the shadcn preset code, so **Get Code**,
  **Open in v0** and shared links still contain the site's own font.
* The lock buttons next to the site's font pickers are hidden with them, so
  fonts cannot be locked against Shuffle.
